## Qué hacemos

Integramos inteligencia artificial y ciberseguridad con tecnología de **NVIDIA** y **Google Cloud**.

## Proyectos públicos

- **[oxm-vision](https://github.com/Oxm-Tech/oxm-vision)**: sistema de vigilancia inteligente multi-cámara para NVIDIA Jetson Orin Nano, con detección de objetos, re-identificación facial, clasificación de audio y dashboard en tiempo real.
- **[nova-glass](https://github.com/Oxm-Tech/nova-glass)**: monitoreo agéntico para una AI Factory (CPU, GPU, red, almacenamiento y updates), con historial persistente, análisis por IA y alertas.
- **[anti-dashboard](https://github.com/Oxm-Tech/anti-dashboard)**: dashboard web de monitoreo en tiempo real para clústeres NVIDIA DGX Spark.
